# Code de conduite

Les échanges restent respectueux et centrés sur les faits techniques. Toute
personne peut contribuer sans discrimination. Harcèlement, menaces, divulgation
de données privées et attaques personnelles sont incompatibles avec le projet.

Décrire les désaccords sans viser les personnes. Signaler un problème de conduite
en privé au propriétaire ou à un mainteneur par le canal déjà convenu ; ne pas
ouvrir d’issue contenant des données sensibles.

Les mainteneurs peuvent demander une correction, retirer un contenu ou limiter
la participation selon la gravité et la répétition. Les signalements sont traités
avec confidentialité ; une contestation peut être adressée au propriétaire.
