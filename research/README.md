# Outils de recherche

Comparaisons isochrones, benchmarks, rapports calculés et anciens chemins de
capture expérimentaux. Aucun runtime produit n’importe ces modules, exclus du
wheel. Après `pip install -e '.[dev]'`, lancer les scripts de `research/scripts/`
depuis la racine du clone. Leurs tests restent dans la collecte pytest commune.

Une comparaison exige les mêmes positions, fenêtres et événements. Une preuve
synthétique ou historique ne qualifie jamais le site courant.
